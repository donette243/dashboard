# AI Ассистент команды

Мини AI dashboard, созданный с использованием React и Groq API

# Проект

Этот проект представляет собой простой AI dashboard, который позволяет пользователю:

- задавать вопросы искусственному интеллекту
- получать AI-ответы
- сохранять последние 5 запросов
- быстро копировать ответы

Проект создан с использованием React и API Groq с моделью LLaMA 3.1.

# Возможности

- Отправка вопросов AI  
- Генерация ответов AI  
- Состояние загрузки (loading)  
- Кнопка копирования ответа  
- История последних 5 запросов  
- Чистый и адаптивный интерфейс
